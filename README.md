# Todo App (MyTodoProject assignment)

This is a simple Django Todo app created as part of the AI Zoomcamp Week 1 assignment.

## Project layout

- `MyTodoProject/` - Django project package and settings
- `todo/` - Django app that implements the todo logic (models, views, templates)
- `db.sqlite3` - local SQLite database (should be ignored by git)
- `.gitignore` - ignores local files and virtual environments

## Features

- List tasks
- Create tasks (title + optional description)
- Toggle task completion
- Delete tasks
- Admin registration for `Task`

## Setup (Windows / PowerShell)

1. Create and activate a virtual environment (optional but recommended):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. Install dependencies (Django is required):

```powershell
pip install django
```

3. Run migrations:

```powershell
python manage.py migrate
```

4. Run the development server:

```powershell
python manage.py runserver
```

Open http://127.0.0.1:8000/ in your browser to view the app.

## Tests

Run the Django test runner:

```powershell
python manage.py test
```

## Notes

- `db.sqlite3` is excluded via `.gitignore`; do not commit it to source control.
